# Ingest, Query, Lint

[[llm-wiki]]의 세 가지 연산.

## Ingest

새 소스를 raw에 넣고 처리를 요청한다. 예시 흐름: LLM이 소스를 읽고 → 핵심을 사용자와 논의 → 위키에 요약 페이지 작성 → index 갱신 → 관련 엔티티·개념 페이지 갱신 → log에 항목 추가. 소스 하나가 10~15개 페이지에 영향을 줄 수 있다. 저자는 **한 번에 하나씩** 처리하며 요약과 갱신을 직접 확인하는 방식을 선호하지만, 감독을 줄인 일괄 처리도 가능하다. 선택한 워크플로우는 스키마에 문서화해 다음 세션에 전달한다.

## Query

위키에서 관련 페이지를 찾아 읽고 인용과 함께 답한다. 형식은 마크다운, 비교표, 슬라이드(Marp), 차트(matplotlib), 캔버스 등. 핵심 통찰: **좋은 답변은 새 페이지로 위키에 다시 저장**한다. 그러면 탐색 결과도 소스처럼 누적된다.

## Lint

주기적 건강 점검: 페이지 간 모순, 새 소스로 대체된 낡은 주장, 인바운드 링크 없는 고아 페이지, 언급만 되고 페이지가 없는 개념, 누락된 상호참조, 웹 검색으로 메울 수 있는 데이터 공백. LLM은 새로 조사할 질문과 찾을 소스도 제안할 수 있다.
