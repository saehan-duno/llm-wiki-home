# LLM 위키

LLM이 원본 자료를 읽고, 서로 연결된 마크다운 위키를 **지속적으로 만들고 갱신**하는 개인 지식베이스입니다.
근거: Andrej Karpathy, "LLM Wiki" — https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f

## 핵심 아이디어

일반적인 RAG는 질문할 때마다 원본에서 조각을 찾아 답하므로 지식이 쌓이지 않습니다.
이 저장소에서는 LLM이 소스를 읽고 위키를 갱신하므로, 상호참조와 요약과 모순 표시가 **누적**됩니다.

- Obsidian = IDE, LLM = 프로그래머, 위키 = 코드베이스
- 사람: 소스 선별, 분석 방향, 질문
- LLM: 요약, 상호참조, 정리, 기록 유지

## 구조

```
raw/            원본 소스 (불변, LLM은 읽기만)
  assets/       소스에 딸린 이미지 등 첨부
wiki/           LLM이 작성·유지하는 마크다운 페이지
  index.md      내용 카탈로그 (ingest마다 갱신)
  log.md        시간순 추가 전용 기록
SCHEMA.md       위키 규칙과 워크플로우 (LLM 에이전트용 지침)
```

## 사용법

1. 소스를 `raw/`에 넣습니다. (Obsidian Web Clipper 등 사용, 이미지는 `raw/assets/`)
2. 에이전트(Claude Code 등)에게 `SCHEMA.md`를 따라 소스를 **ingest** 하라고 요청합니다. 한 번에 하나씩 처리하는 것을 권장합니다.
3. 위키에 질문(**query**)합니다. 좋은 답변은 위키 페이지로 다시 저장합니다.
4. 주기적으로 **lint**를 요청해 모순, 고아 페이지, 누락된 링크를 점검합니다.

## 참고

- Claude Code가 `SCHEMA.md`를 자동으로 읽게 하려면 `CLAUDE.md`에 "위키 작업은 SCHEMA.md를 따른다"는 한 줄을 추가하세요.
- 위키가 커지면 검색 도구(예: qmd)를 붙일 수 있습니다. 약 100개 소스, 수백 페이지까지는 `index.md`만으로도 충분하다고 합니다.
